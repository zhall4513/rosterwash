# Architecture
Next.js 16 TypeScript monolith. PostgreSQL via `pg` in production and persistent PGlite for local development. SQL migrations live in `db/migrations`. Auth uses scrypt password hashes, random opaque session tokens stored only as SHA-256 hashes, HTTP-only same-site cookies, and server-side role checks. Durable jobs use PostgreSQL `FOR UPDATE SKIP LOCKED`, retries and idempotency keys. The cron endpoint requires a bearer secret. Railway is the intended host. Email is optional Resend integration. Stripe Connect standard-account onboarding is implemented in test mode; payment collection is intentionally gated.
