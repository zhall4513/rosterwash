# Deployment
Railway deployment is not yet configured. Create an app and PostgreSQL service, set `DATABASE_URL`, `APP_URL`, `CRON_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` (only during provisioning), and optional email/Stripe secrets in Railway variables. Build with `npm ci && npm run build`, migrate with `npm run db:migrate`, provision the owner with `npm run admin:create`, start with `npm start`. Schedule authenticated POST `/api/cron` using `Authorization: Bearer $CRON_SECRET` every minute. Use HTTPS and configure provider webhook routes before enabling billing. Connect `rosterwash.com` only after domain ownership and production readiness are verified. Never enable intake before coverage review.
